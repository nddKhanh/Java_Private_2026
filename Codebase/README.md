# Codebase — HitShop BTVN buổi 05

Codebase được cập nhật từ `Codebase/src` trên nhánh `develop` theo đề `Lesson5/buoi-05-btvn.md` của nhánh `main`.

Giữ cách viết Java console với `Scanner`, `switch-case`, vòng lặp `for`, method `static` và thông báo tiếng Việt.

## Chạy chương trình

Mở terminal tại `Codebase/src`:

```powershell
javac -encoding UTF-8 *.java
java HitShop
```

## Chức năng

1. Thêm đơn hàng.
2. Xem danh sách đơn hàng.
3. Sửa đơn hàng theo ID.
4. Xóa đơn hàng theo ID.
5. Kiểm tra sản phẩm có đắt không.
6. Thanh toán qua MoMo hoặc HITBank.
0. Thoát.
